# Project 1 - Victoria Island Travel Brochure

## Description

Project 1 is a responsive travel brochure website based on Victoria Island from MapleStory. The website allows visitors to learn about Victoria Island, view available travel packages, and submit a travel inquiry form.

The website was created using HTML and CSS and demonstrates semantic HTML, CSS Grid, Flexbox, CSS variables, tables, forms, images, and responsive web design.
